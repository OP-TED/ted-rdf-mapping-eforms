== Release notes
*April 2026*

* Updated Mappings of eForms Notices from link:https://github.com/OP-TED/ePO/tree/v4.0.0[ePO 4.0.0] to link:https://github.com/OP-TED/ePO/tree/v5.2.0[ePO 5.2.0].

* Added Mappings for Unpublish Fields for eForms SDK 1.3 - 1.13

* This release addresses the following GitHub issues:
** Issue #122: Conflated VehicleInformation properties, empty instances
** Issue #123: Missing privacy condition for BT-09(b)-Procedure hasCrossBorderLaw
** Issue #124: Conflated BT-5010-Lot isFundedBy Fund adms:identifier values
** Issue #126: Conflated BT-133-Lot definesOpeningPlace values
** Issue #127: Empty LotGroupAwardInformation in LotGroup announcesLotGroupAwardInformation
** Issue #128: Missing currency for BT-156-NoticeResult in NoticeAwardInformation
** Issue #129: Unlinked/orphan ContractTerm with definesPaymentExecutor ND-PayerParty
** Issue #130: Runt/empty Procedure instance in DirectAwardTerm refersToPreviousProcedure
** Issue #151: Conflated hasPlaceOfPerformanceAdditionalInformation and specific/broad place mixup
** Issue #152: announces_refersTo_lotGroup.patch Missing announces/refersTo LotGroup under ND-LotsGroup
** Issue #153: legal_basis_description.patch Missing BT-01(c)-Procedure legal basis ID if description is absent
** Issue #154: award-criterion-threshold.patch Missing AwardCriterion threshold Constraint linkage
** Issue #155: definesLotGroup.patch Wrong definesLotGroup mapping
** Issue #156: refersToPreviousNotice.patch Possibly wrong mapping for refersToPreviousNotice for notices without ChangeReason
